# QCatGrayWidgets

The QCatGrayWidgets module provides a set of ui components for the corresponding scenario.

## Examples

| Project | README |
|:--:|:--:|
| qcustomplotwidget | qcustomplot chart use case  |
| qrencodewidget | Qr code use cases |
| screenshotstools | Screenshot magnifying glass case |

## Submodule

CmakeLists.txt in the QCatGrayWidgets main directory is responsible for introducing the submodules of the src directory, each of which does not directly depend on each other.
